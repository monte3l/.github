# Support

| You want to                     | Go to                                                                        |
| ------------------------------- | ---------------------------------------------------------------------------- |
| Ask how to use something        | Open an issue in the repository and choose **Question**                      |
| Report a bug                    | Open an issue and choose **Bug report**                                      |
| Suggest a feature               | Open an issue and choose **Feature request**                                 |
| Report a problem in the docs    | Open an issue and choose **Docs problem**                                    |
| Report a security vulnerability | Use private vulnerability reporting, see [`SECURITY.md`](SECURITY.md)        |

Maintainers work on these projects in their own time. Include the version,
what you ran, and what you expected, and the answer will come sooner.

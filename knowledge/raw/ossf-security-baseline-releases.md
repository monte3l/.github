# OpenSSF Security Baseline releases

**Source:** https://github.com/ossf/security-baseline/releases · **Kind:** primary · **Accessed:** 2026-11-19

## What it says

- The repository publishes tagged releases. On 2026-11-19 the newest was `v2026.08.28`, released 2026-08-28, and one older tag, `v2026.02.19`, exists (GitHub API).
- The Baseline's requirements are YAML files under `baseline/` in the repository.

## Caveats

- Only one GitHub release exists, so a watcher on `releases/latest` sees one tag and reacts when the next is published. The cadence is not established: two tags in about six months.
- The Best Practices criteria follow the Baseline, so a new release can trigger two watched sources at once.

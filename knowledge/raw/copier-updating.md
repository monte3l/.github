# Copier: updating a project

**Source:** https://copier.readthedocs.io/en/stable/updating/ · **Kind:** primary · **Accessed:** 2026-11-19

## What it says

- Copier documents a `copier update` command that brings a project generated from a template up to a newer template version, an answers file (`.copier-answers.yml`) that records how it was generated, and the handling of conflicts.
- Version 9.19.1 was released on 2026-10-13 (GitHub API), so it is actively maintained.

## Caveats

- The page was checked only for those three topics. That it needs a git-tagged template and a clean working tree, and that it regenerates the old and new versions and re-applies the local diff, comes from a research agent.

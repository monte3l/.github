# OpenSSF scorecard-monitor

**Source:** https://github.com/ossf/scorecard-monitor · **Kind:** primary · **Accessed:** 2026-11-19

## What it says

- Aggregates Scorecard scores into a markdown report and a JSON database, can open an issue when a score changes, and can discover an organization's repositories.

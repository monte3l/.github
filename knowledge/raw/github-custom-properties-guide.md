# Managing custom properties in an organization (guide)

**Source:** https://docs.github.com/en/organizations/managing-organization-settings/managing-custom-properties-for-repositories-in-your-organization · **Kind:** primary · **Accessed:** 2026-11-25

## What it says

- The page does not state which GitHub plans can use organization custom properties.
- Its only plan statement is about Copilot's suggested allowed values for single select and multi select properties: "This feature is available with Copilot Business or Copilot Enterprise."
- Setting values: users and apps with the repository-level "custom properties" fine-grained permission can set values, but only for a property with **Allow repository actors to set this property** enabled.
- Viewing values: anyone with read permission to a repository can see its values and cannot edit them.

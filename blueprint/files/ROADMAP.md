# Roadmap

What {repo} intends to do, and not do, over roughly the next year. It lists what
is still ahead. What has shipped is in the git history and the GitHub releases.
Work that can be closed is a GitHub issue, linked from here. Statements that
stay true until something changes are written here.

## Now

What is being worked on or released next. Link each item to its issue or
milestone. Leave the section as a single sentence if nothing is under way.

## Next 12 months

What the project means to do, in the order it expects to. Say what would change
the plan. An item only becomes an issue once someone commits to it, until then
it is a line here or a Discussion in the Ideas category.

## Known limits

What the project does not do or does only partly, and has chosen to accept. Each
entry says what the limit is, who it affects and what would change it. Link the
issue if a fix is planned.
